# Modelo do `00 Status.md`

Copie este modelo para a pasta do produto e preencha.

```markdown
# [Nome do produto] · Status

**Fase atual:** [número e nome]
**Próximo passo:** [o que vem agora, em uma frase]
**Atualizado em:** [data]

## Briefing
- Produto e tipo:
- Especialista:
- Público (país, idioma, gênero, idade):
- Preço pensado:
- Formato de venda:
- Quiz no funil: sim / não
- O que já existe:

## Fases
| # | Fase | Situação | Data | Entrega |
|---|---|---|---|---|
| 0 | Kickoff | concluída | | este arquivo |
| 1 | Pesquisa | pendente | | |
| 2 | Mecanismo e tese | pendente | | |
| 3 | Oferta | pendente | | |
| 4 | Quiz | pendente / não se aplica | | |
| 5 | Copy | pendente | | |
| 6 | Teste | pendente | | |

Situação: pendente, em andamento, concluída, pulada (com motivo).

## Decisões principais
- [data] [decisão] (ex.: One Belief aprovada, preço definido, formato da VSL)

## Pendências
- [o que está faltando: provas, respostas do especialista, gravações]
```
